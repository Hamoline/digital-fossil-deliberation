# The Digital Fossil of Deliberation

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24348597.svg)](https://doi.org/10.5281/zenodo.24348597)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Human-centered AI decision provenance and statutory privacy accountability architecture (W3C PROV-O schemas, Microsoft Teams Adaptive Card review gates, and Safe Start risk-intake rubrics).

## Repository Contents

* **[`w3c_prov_o_split_storage_schema.md`](w3c_prov_o_split_storage_schema.md)** — Split-storage data model separating immutable W3C PROV-O provenance metadata and SHA-256 hashes from time-bounded PII payloads for statutory compliance (BC FOIPPA Sections 28, 30, 31, and 69).
* **[`adaptive-card-gate.json`](adaptive-card-gate.json)** — Hardened Microsoft Teams Adaptive Card v1.5 payload capturing State A $\rightarrow$ State B human edits, deliberation notes, and explicit accountability attestations.
* **[`safe_start_3_axis_risk_intake_rubric.md`](safe_start_3_axis_risk_intake_rubric.md)** — 3-axis risk-scoring rubric determining when AI-assisted workflows require mandatory human-in-the-loop deliberation gates.
